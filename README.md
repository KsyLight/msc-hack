# msc-hack

## Подготовка данных и EDA

Финальный pipeline подготовки данных находится в `LCT2026_final_EDA.ipynb`

Ноутбук:
- проверяет и объединяет журналы событий за 2019–2026 годы;
- формирует эпизоды состояния `Неисправен`;
- строит признаки только по данным, доступным до момента прогноза;
- формирует бинарный target `target_fault_24_48h` - новое зарегистрированное начало `Неисправен` в интервале `[t + 24h, t + 48h)`;
- выполняет временное разделение на train / validation / test;
- проводит EDA и проверки на утечки и корректность данных;
- сохраняет готовые таблицы и описание признаков для обучения моделей.

### Запуск

Для запуска необходимы журналы `ext-journal-2019.csv` ... `ext-journal-2026.csv` и исходные справочники.

После размещения данных рядом с ноутбуком выполните `Restart Kernel and Run All`

При другом расположении исходных данных необходимо изменить `DATA_DIR`.

### Результаты

После выполнения создаётся каталог `data_handoff`, в том числе:

- `ml_ready/train.parquet`
- `ml_ready/train_compact.parquet`
- `ml_ready/validation.parquet`
- `ml_ready/test.parquet`
- `ml_ready/scoring_latest.parquet`
- `feature_list.json`
- `feature_dictionary.csv`
- audit-таблицы и дополнительные диагностические файлы

Большие сгенерированные `.parquet` файлы в Git не хранятся.
