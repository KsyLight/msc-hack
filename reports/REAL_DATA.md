## Проверки и покрытие

Проверены все строки используемых ML-выборок: уникальность channel/time, метки 0/1, границы `[t+24h,t+48h)`, прошлое время признаков, допустимость состояния, полнота наблюдения целевого интервала и inverse sampling weights. Train: 01.02.2019–30.12.2024; validation: 01.01–30.12.2025; test: 01.01–28.06.2026. Окна разных выборок не пересекаются. SHA-256 и результаты проверок: [real_data_audit.json](real_data_audit.json).

Подключено 5 633 канала датчиков и 512 каналов насосов/вентиляторов — всего 6 145. Ещё 2 093 канала относятся к другим типам (фазы, переключатели и др.). Для каждого подключённого канала найдены система и объект. Текущий справочник не доказывает историческую привязку.

В ежедневных журналах 30 695 389 событий, 195 422 тревожных сообщения и 113 413 сообщений неисправности. Нет данных за 01.06.2026: API возвращает null, график оставляет разрыв. 13 строк channel/day без текущей привязки включены в общие счётчики, но не в ряды отдельных направлений. Прогнозы и наблюдения разделены в API. История сигналов не выдаётся за размеченные ложные сработки.

## Модели

27 прошлых счётчиков и отношений. Метаданные, целевые признаки, будущая наблюдаемость и смешанные физические измерения не входят в X. Обучены LogisticRegression и HistGradientBoosting; оба победителя выбраны по average precision на validation. Дополнительного прореживания compact не было. Метрики — по строкам channel/day, не по уникальным авариям.

|---|---:|---:|---:|---:|---:|---:|---:|
| Датчики · HistGradientBoosting | 439 508 | 1 894 618 | 985 427 | 1 240 | 0.0922 | 0.1387 | 0.0402 |
| Насосы/вентиляторы · HistGradientBoosting | 66 177 | 154 826 | 75 681 | 4 623 | 0.1349 | 0.4560 | 0.1376 |

**Требования кейса к качеству пока не выполнены.** Цель — сообщение «Неисправен» через 24–48 часов; подтверждённые физические отказы, износ конструкций и пожары в поставке не размечены. Сырой балл модели не является калиброванной вероятностью аварии. Метрики, пороги и версии: [real_model_metrics.json](real_model_metrics.json).

## Воспроизведение

```powershell
conda activate msc-hack
python -m scripts.train --handoff data
# В .env установить APP_MODE=real
docker compose up --build -d
```

Адреса: http://localhost:8000 и http://localhost:8000/docs. Для фронтендера: JSON API уже содержит `system_type`, `sensor_name`, `system_tag`, покрытие типов и `GET /api/observations?days=90`. Замена модели сохраняет прежний контракт REST; список признаков берётся из `GET /api/models`.

Проверки: 25 Python-тестов, production-сборка фронтенда, сборка/запуск Docker и браузерный сценарий Edge. В работающем API — 74 объекта, 6 012 оценок и 133 канала без оценки. Повторный расчёт идемпотентен; CSV, поиск по справочнику и null за пропущенный день проверены на реальных артефактах. [Подробности](VALIDATION.md).
